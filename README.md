# CliniCore - Website Clone

Same design, same layout 1:1 offline-ready clone of [CliniCore Medical & Healthcare Demo](https://clinicore.cmsmasters.studio/main/).

## Structure

- `index.html` — The complete cloned website with all sections, navigation, hero, services, doctor profiles, testimonials, appointment forms, and footer.
- `assets/`
  - `css/` — All 66 Elementor & CMSMasters stylesheets
  - `js/` — All 43 interactive scripts (Swiper, jQuery, animations)
  - `images/` — All images, badges, logos, and SVGs (100+ files)
  - `fonts/` — All font files and icons (`eicons`, `cmsmasters-icons`, `forminator-icons`)
- `server.js` — Lightweight local web server

## How to Run

### Method 1: Local Server (Recommended)
Run the built-in server:
```bash
node server.js
```
Then open [http://localhost:3000](http://localhost:3000) in any browser.

### Method 2: Direct File Open
You can also directly double-click or open `index.html` in your web browser (Google Chrome, Microsoft Edge, Firefox, Safari).
